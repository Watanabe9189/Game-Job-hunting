//<****************************************************************
//操作方法
//<****************************************************************
//<====================================
・キーボード操作
WASD->移動
マウス操作->カメラ回転
RSHIFT押しながら移動->ダッシュ
SPACEキー隠れる・アイテムを拾う
//<====================================
・スティック操作
左スティック->移動
右スティック->カメラ回転
LB押しながら移動->ダッシュ
Bボタン->隠れる・アイテムを拾う
//<====================================
//スクリーンモード変更
//0キー->スクリーンモードの切り替え
//<====================================
